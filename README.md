# ⛳ Golf AI Caddy

> 完全免费的极简高尔夫记录 + AI分析小程序

## 产品定位

专为高尔夫爱好者设计的智能数据记录与分析平台。通过AI技术帮助用户深入了解自己的球技，明确提升方向。

## 核心特色

- 🆓 **完全免费** - 所有功能免费使用
- 🎯 **极简界面** - 告别复杂臃肿，专注记录与分析
- 🤖 **AI赋能** - 不只记录成绩，更提供个性化分析与提升建议
- 🔒 **隐私优先** - 用户完全掌控数据可见性

## 核心功能

### 成绩记录
- 每场总杆数 + 每洞杆数
- 球友成绩记录
- 渐进式记录（从简单到详细）

### AI分析
- 赛后智能总结
- 成长轨迹追踪
- 练习建议生成

### 游戏积分
- 多种高尔夫游戏计分规则
- 自动计算积分

### 隐私设置
- 完全私有模式
- 好友可见模式
- 球队内可见

## 技术栈

- 前端：微信小程序原生开发
- 后端：微信云开发
- AI：大模型API（腾讯混元/OpenAI）

## 版本规划

- V1.0 MVP：基础成绩记录 + AI赛后总结
- V1.5：游戏积分 + 球队功能
- V2.0：详细数据记录 + 成长轨迹
